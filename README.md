# 智能更衣柜安卓终端

面向场馆储物柜中控设备的 Android 前端项目。终端支持按场地配置数字密码、人脸、IC 卡、掌纹/掌静脉和二维码等身份识别方式，并与甲方现有后端管理系统及柜控硬件对接。

## 当前阶段

项目目前处于需求与交互设计阶段，已整理：

- 存柜、取柜、单柜归还与一键归还流程
- 柜格空闲、占用、不可用等状态展示
- 会员等级与可用柜数权限
- 多种识别硬件的动态配置和并行监听
- Android APK 交付、接口边界与异常处理要求

详细设计见 [智能更衣柜安卓终端需求与交互设计](docs/superpowers/specs/2026-07-30-smart-locker-android-terminal-design.md)。

## 交付范围

- Android 终端前端源码
- 可安装 APK
- 后端 API 与硬件 SDK 接入层
- 第三方依赖及许可证清单

后端管理系统、业务数据库和柜控服务由甲方提供。
