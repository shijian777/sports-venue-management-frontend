# 体育场馆管理系统前端

面向体育场馆的前端项目，目前已有内容聚焦储物柜中控终端的需求和交互设计：规划存取柜、柜格状态、会员柜数权限、数字密码、人脸、IC 卡、掌纹/掌静脉和二维码识别，以及后端和柜控硬件接口。

## 文件与功能

- `README.md`：本项目独立的功能简介、当前阶段和范围。
- `docs/superpowers/specs/2026-07-30-smart-locker-android-terminal-design.md`：储物柜终端的详细需求与交互设计。
- `.gitignore`：本地构建与临时文件排除规则。

当前仓库只有说明和设计资料，尚无可构建的前端应用或 APK。场地预约、赛事、收费等完整场馆业务也尚未在此仓库实现。

## 当前阶段

项目目前处于需求与交互设计阶段，已整理：

- 存柜、取柜、单柜归还与一键归还流程
- 柜格空闲、占用、不可用等状态展示
- 会员等级与可用柜数权限
- 多种识别硬件的动态配置和并行监听
- Android APK 交付、接口边界与异常处理要求

详细设计见 [体育场馆管理系统前端：储物柜终端设计](docs/superpowers/specs/2026-07-30-smart-locker-android-terminal-design.md)。

## 规划交付范围

- Android 终端前端源码
- 可安装 APK
- 后端 API 与硬件 SDK 接入层
- 第三方依赖及许可证清单

后端管理系统、业务数据库和柜控服务由甲方提供。
