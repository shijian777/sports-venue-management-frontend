# 体育场馆管理系统前端

面向体育场馆的前端项目，目前内容聚焦储物柜中控终端的需求与交互设计。

## 功能规划

- 存柜、取柜、单柜归还与一键归还。
- 柜格空闲、占用、不可用状态展示。
- 会员等级与可用柜数权限。
- 数字密码、人脸、IC 卡、掌纹/掌静脉和二维码识别方式配置。
- Android 终端与现有后端 API、柜控硬件 SDK 对接。

## 当前阶段

当前仓库只有说明和设计资料，尚无可构建的前端应用或 APK。场地预约、赛事、收费等完整场馆业务尚未在此仓库实现。规划交付包括 Android 前端源码、APK、后端及硬件接入层和依赖清单；后端管理系统、业务数据库与柜控服务由甲方提供。

详细资料见 [体育场馆前端：储物柜终端设计](docs/superpowers/specs/2026-07-30-smart-locker-android-terminal-design.md)。
